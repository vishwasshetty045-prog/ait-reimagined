# AIT Reimagined — Student Discovery & Admissions Experience

Independent redesign concept for Acharya Institute of Technology (AIT), Bengaluru. This is **not** an official AIT website.

## What is included
- Home
- Program Explorer with search/filter + compare drawer
- Flagship AI & ML program page
- Placements & career-readiness page
- Campus Life page
- Searchable/filterable demo Events hub
- Admissions page with 4-step planner and validated prototype enquiry form
- Smart rule-based Course Finder with top-3 recommendations
- Contact / Visit page
- Global Ctrl/Cmd+K search
- Responsive mobile navigation and sticky mobile CTAs

## Deploy
This repository is ready for static hosting such as GitHub Pages, Netlify, or Cloudflare Pages.

## Important
Institutional facts in this prototype were based on public AIT information available during the redesign. Revalidate all facts, admissions requirements, contacts, and program information before a real production launch.

## Image note
The prototype references a few public campus photographs for private demonstration. Before any public/production deployment, replace them with AIT-approved media or obtain appropriate permission/licensing.
